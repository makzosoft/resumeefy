Connect to GitHub

A plain local file can't do full GitHub sign-in (that needs a server), so this uses a Personal Access Token instead — it works entirely from your phone, no hosting needed.

  1. Go to github.com/settings/tokens
  2. Generate a token (classic is simplest) with the repo scope
  3. Paste it below — it's stored only in this browser, on this device
